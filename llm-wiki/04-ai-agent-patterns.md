# 04｜AI Agent（智慧代理人）：從陪聊進化為自主工作流

## 核心定義
傳統的聊天機器人屬於「單次呼叫（Single-turn）」，使用者問一句、AI 憑直覺答一句就結束了[cite: 5]。
**AI Agent（智慧代理人）** 則是以大語言模型為推理核心，賦予它**任務拆解（Planning）**、**調用外部工具（Tool Use）** 以及 **自我反思修正（Reflection）** 的能力[cite: 1, 2, 5]。Agent 能夠像人類處理專案一樣，透過多步驟的迴圈（Loop）與決策圖（Graph）反覆檢查產出品質，直到達成目標為止[cite: 1, 5]。

## 生活化比喻
**「從只會動口的客服，升級為會查系統又會自我檢查的專案助理」**
* **一般 LLM**：像電話客服，只能憑腦袋裡的印象直接回答客戶，算錯數字或漏看條件也不知道。
* **AI Agent**：像資深專案助理，接到任務後會先列待辦清單（Planning），遇到算術就打開計算機或查資料庫（Tool Use），寫完報告後還會自己切換成「主管視角」檢查有沒有錯字與邏輯漏洞，修改確認無誤後才交卷（Reflection）[cite: 2, 5]。

## 關鍵技術詞彙
* **AI Agent（智慧代理人）**：能夠感知環境、自主規劃步驟、使用工具並透過迭代迴圈完成複雜目標的 AI 系統[cite: 1, 2, 5]。
* **Reflection（自我反思迴圈）**：讓模型先產出初稿（Draft），再由審查角色挑出缺點（Critique），最後重構出高品質版本（Refine）的設計模式[cite: 1, 5]。
* **Tool Use / Function Calling（工具調用）**：讓 LLM 自主決定何時呼叫外部程式（如搜尋引擎、計算機、資料庫 API）來彌補自身能力限制。
* **Planning（任務規劃）**：將一個龐大模糊的指令，自動拆解成多個可依序執行的子任務步驟。
