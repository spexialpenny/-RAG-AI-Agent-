# 02｜RAG（檢索增強生成）：幫 AI 裝上知識外掛

## 核心定義
**RAG（Retrieval-Augmented Generation，檢索增強生成）** 是一種在不重新訓練模型權重的前提下，讓大語言模型具備最新或特定領域知識的架構[cite: 3, 5]。
其運作流程分為三個階段：
1. **檢索（Retrieve）**：當使用者提出問題時，系統先從外部知識庫（如 PDF、法規手冊、個人 Wiki）搜尋出最相關的數段原文[cite: 3, 5]。
2. **增強（Augment）**：將檢索到的原文片段連同使用者的問題，一起組裝進提示詞（Prompt）中[cite: 3, 5]。
3. **生成（Generate）**：要求 AI 嚴格根據這份參考資料來組織語言並回答問題，若資料未記載則誠實回答不知道[cite: 3, 5]。

## 生活化比喻
**「允許攜帶指定課本的開書考」**
RAG 就像是把原本的「閉書考試」改成「開書考試（Open-Book Exam）」。考官在考場發給考生一本指定的《公司規章手冊》，並規定：「所有答案必須從這本手冊裡找，不准自己亂猜。」考生收到題目後，先翻找相關頁面（檢索），再把找到的條文抄寫整理成通順的答案（生成）。

## 關鍵技術詞彙
* **RAG（檢索增強生成）**：結合「外部資料檢索」與「LLM 文本生成」的混合式 AI 系統架構[cite: 3, 5]。
* **Chunking（文本切塊）**：將長篇文章切割成適合檢索與閱讀的小段落（例如每 200 字一塊），避免一次塞入過多無關資訊[cite: 2, 3, 5]。
* **Context Injection（上下文注入）**：將檢索出來的參考資料片段放入 System Prompt 中，作為模型回答的依據[cite: 3, 5]。
* **Grounding（事實錨定）**：限制 AI 的回答必須緊扣提供的外部事實依據，大幅降低幻覺發生率[cite: 3, 5]。
