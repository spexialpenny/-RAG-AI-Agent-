# 03｜電腦如何看懂文字語意？Embedding 與向量資料庫

## 核心定義
傳統的關鍵字搜尋（如 `Ctrl + F`）只能比對「一模一樣的字面」，如果文件寫「電腦當機」，使用者搜尋「筆電畫面卡死」，傳統搜尋就會找不到。
為了解決這個問題，RAG 系統會透過 **Embedding（詞嵌入）模型**，將每一段文字轉換成一串由小數點組成的**多維空間向量（數字座標）**[cite: 3, 5]，並存入**向量資料庫（Vector Database，例如 Chroma）**[cite: 3, 5]。語意越相近的句子，在空間中的距離就越靠近，系統就能透過計算向量距離找出意思相近的段落[cite: 3, 5]。

## 生活化比喻
**「大型圖書館的語意座標系統」**
想像一座巨大的圖書館，書架不是按照筆畫排列，而是按照「內容主題的空間座標」擺放。〈如何煮義大利麵〉與〈番茄肉醬食譜〉雖然書名沒有半個字重複，但因為語意相近，會被放在相鄰的書架座標上；而〈微積分導論〉則會被放在很遠的另一區。找資料時，只要把問題轉換成座標，去抓附近最近的幾本書即可。

## 關鍵技術詞彙
* **Embedding（詞嵌入 / 向量化）**：將文字、圖片等非結構化資料映射為連續數字向量的技術，用來捕捉語意特徵[cite: 3, 5]。
* **Vector Database（向量資料庫）**：專門用來儲存、索引與高速比對高維度向量的資料庫（如 Chroma、Pinecone）[cite: 3, 5]。
* **Cosine Similarity（餘弦相似度）**：衡量兩個向量之間夾角餘弦值的數學指標，數值越接近 1 代表兩段文字語意越相似[cite: 3, 5]。
* **Semantic Search（語意檢索）**：理解使用者提問背後的真實意圖與語意，而非僅依賴字面關鍵字比對的搜尋方式[cite: 3, 5]。
