# 05｜RAG 與 AI Agent 的差異與實務整合

## 核心定義
RAG 與 AI Agent 並非互斥的替代品，而是解決不同層面問題的互補技術：
* **純 RAG 系統** 專注於「知識的精準獲取」，採用固定的檢索管線（Deterministic Pipeline），適合單純的問答與資料查詢[cite: 3, 5]。
* **AI Agent 系統** 專注於「行動與決策的自動化」，具備動態判斷與自我修正迴圈[cite: 1, 5]。
* **Agentic RAG（代理人檢索增強生成）** 則是兩者的結合體：由 Agent 自主判斷「需要查哪份資料」、「查出來的資料夠不夠完整」，若不夠甚至會自動改寫關鍵字重新檢索。

## 生活化比喻
**「知識大腦與行動雙手的分工」**
* **RAG 是「知識大腦」**：負責儲存正確且最新的專業記憶，確保講出來的每句話都有憑有據[cite: 3, 5]。
* **AI Agent 是「行動雙手」**：負責思考先後順序、操作各種軟體工具，並在交出成品前反覆檢查品質[cite: 2, 5]。
只有大腦沒有雙手，只能回答問題而無法執行複雜任務；只有雙手沒有大腦，做事則容易缺乏專業依據。兩者結合才是現代 AI 應用的完整形態。

## 關鍵技術詞彙
* **Agentic RAG（代理人檢索增強生成）**：將 RAG 檢索流程納入 Agent 決策迴圈中，讓 AI 能動態評估檢索品質並進行多輪查詢。
* **Deterministic Pipeline（固定管線）**：步驟完全寫死、依序執行的程式流程（例如：輸入 $\rightarrow$ 檢索 $\rightarrow$ 生成）[cite: 3]。
* **Autonomous Loop（自主迴圈）**：允許系統根據中間檢查結果（Gate），決定要繼續往下一步推進，還是退回上一步重新生成[cite: 1, 5]。
